# ADR 0005: Workspace ↔ Location model

## Status
Proposed

## Context
Constitution allows one Workspace spanning many Locations, or one per region.

## Recommendation (P0 default)
- Single-location: 1 Org · 1 Location · 1 Workspace  
- Multi-location: 1 Org · N Locations · 1 Workspace with Location filters  
- Enterprise rollup: optional HQ Workspace later (P1)
