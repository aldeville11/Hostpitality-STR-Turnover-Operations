# Vinton Adler landing page (CRO rebuild)

This directory contains a full rebuild of the [aldeville11/vinton-adler](https://github.com/aldeville11/vinton-adler) marketing site.

## Why it is in this repo

This cloud agent run was attached to `Hostpitality-STR-Turnover-Operations`, while the requested work targets `vinton-adler`. The agent token can push here but not to `vinton-adler`.

## How to apply

1. Copy this folder’s contents into a branch on `aldeville11/vinton-adler` (replace that repo’s root).
2. Or merge the source files from this tree into that repo’s root.
3. Run `npm install && npm run build && npm run dev`.
